# Quickstart

CodeGraph Context is a hosted remote MCP for code graph MCP for AI coding.

## Fast Path

1. Open CodeGraph Context and select the buyer plan.
2. Create or request a bearer token from the hosted product.
3. Add https://codegraphcontext.clauxel.com/mcp to a compatible MCP client.
4. Run tools/list, then call repo_graph_query with public-safe sample data.
5. Save the returned receipt or export for human review.
